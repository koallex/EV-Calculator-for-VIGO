# EV Calculator for VIGO/Nammi 06/Evolute i-joy

Веб-приложение для расчёта и анализа расхода энергии электромобиля VIGO на маршруте.

## Основные возможности

- Расчёт прогнозируемого остаточного SOC по маршруту.
- Сегментный расчёт маршрута с учётом различий скорости на отдельных участках.
- Учёт факторов, влияющих на расход:
  - скорость;
  - температура;
  - ветер и его направление;
  - осадки и их интенсивность;
  - рельеф;
  - рекуперация;
  - климат-контроль;
  - другие калибровочные коэффициенты модели.
- Отображение факторов расхода в калькуляторе.
- HUD для предварительного прогноза и мониторинга поездки.
- GPS-трекинг во время движения.
- Анализ фактического расхода и отклонения от предварительного прогноза.
- Постепенная калибровка модели по реальным поездкам.

## Погодные данные

При построении маршрута приложение получает необходимые погодные данные и использует их для расчёта сегментов.

Во время активного GPS-трекинга HUD обновляет погодные данные примерно каждые 15 минут, если автомобиль движется. Обновляются температура, скорость и направление ветра, осадки и погодные параметры.

История уже пройденного участка не пересчитывается по новой погоде — обновляется прогноз для оставшегося маршрута.

## Рельеф и API

Рельеф маршрута не запрашивается заново на каждой GPS-точке. Полученные данные используются локально во время трекинга.

Это позволяет минимизировать количество обращений к внешним API и снижает риск превышения бесплатных лимитов.

## Расчёт скорости

Расход по скорости использует калибровочную кривую, которая применяется как в калькуляторе, так и в HUD.

Текущая рабочая область скоростей 70–105 км/ч сглажена для исключения резкого изменения расхода после 70 км/ч. Значения продолжают корректироваться по результатам реальных поездок.

## Климат-контроль

Модель учитывает расход климат-контроля как временную составляющую, а не только как фиксированный расход на 100 км.

Для холодной погоды учитывается работа теплового насоса и дополнительная нагрузка ТЭНа. Коэффициенты постепенно калибруются по фактическим поездкам.

## HUD

HUD предназначен для оперативного контроля поездки:

- текущий SOC;
- прогноз SOC на финише;
- текущая и средняя скорость;
- фактически пройденное расстояние;
- прогнозируемый расход;
- влияние погодных условий и других факторов;
- отклонение фактического расхода от расчётного.

Во время трекинга расчёт выполняется локально на основе GPS и ранее полученных данных. Погодные данные периодически обновляются отдельными запросами.

## Административный доступ

В приложении предусмотрена авторизация пользователей и отдельный административный интерфейс для управления доступом пользователей.
