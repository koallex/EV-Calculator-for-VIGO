# Minsk Air Radar

Мобильный веб-прототип карты воздушной обстановки вокруг Минска.

## Что изменилось
- Источник данных: **adsb.lol** (надёжнее OpenSky с Vercel/облачных IP).
- Улучшена мобильная адаптация (safe-area, touch, тёмная тема, PWA-метатеги).
- Подсветка выбранного борта, больше деталей (тип ВС, вертикальная скорость).
- Стабильная обработка ошибок и кэширование на edge.

## Развёртывание
1. Загрузите содержимое в GitHub-репозиторий.
2. Импортируйте в [Vercel](https://vercel.com) → Deploy (сборка не нужна).
3. Откройте адрес на смартфоне.

## Локальный запуск (опционально)
```bash
npx serve .
# или любой static server + прокси /api на aircraft.js
```

Для полноценного локального API можно использовать Vercel CLI:
```bash
npx vercel dev
```

## Важно
- Данные публичные ADS-B, возможны задержки и пропуски.
- Обновление раз в 15 секунд.
- Демо-инструмент, не для оперативного управления воздушным движением.
- Карта: OpenStreetMap + Leaflet через CDN.
